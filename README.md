### Planeja API – API de Planejamento

Desenvolvimento de uma API REST utilizando Java e Spring Boot, como parte do projeto Planeja, com foco na construção de uma aplicação backend organizada, seguindo boas práticas de desenvolvimento e separação de responsabilidades.

O projeto contempla a implementação de endpoints para gerenciamento de cartões, utilizando arquitetura em camadas (Controller, Service e Repository), validação de dados de entrada, mapeamento de objetos e tratamento global de exceções.

**Principais recursos implementados:**
- Criação e consulta de cartões por meio de endpoints REST.
- Validação de dados com Bean Validation.
- Tratamento global de exceções.
- Separação de responsabilidades entre as camadas da aplicação.
- Persistência de dados com Spring Data JPA.

**Stack tecnológica:**
Java 25, Spring Boot 4, Spring Web, Spring Data JPA, Hibernate, H2 Database, MapStruct, Lombok, Maven e Git.
